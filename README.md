# Flake

Прототип PvP-моду для **Fabric / Minecraft 26.3 / Java 25**.

## Керування

| Клавіша | Дія |
| --- | --- |
| **G** | Клас і білд; звідси також відкривається меню лобі |
| **H** | Активна здібність класу |
| **L** | Кастомне меню лобі: створення, вхід, готовність, вихід |
| **Tab** | Кастомна панель гравців: клас, PvP-вбивства, смерті, ping і готовність |
| **PageUp / PageDown** з утриманим Tab | Сторінки списку гравців |

Клавіші можна переналаштувати в налаштуваннях Minecraft. Статистика Tab — за весь час у цьому світі, **не рахунок раунду**.

## «Контужений»

Вибір: **G → Контужений** або `/flake class concussed`.

**H → накопичення → стискання до сингулярності → вибух і відкидання.** Заряд триває 1,1 с при 20 TPS, тестовий радіус — 5 блоків, КД — 3 с від натискання. Хвиля діє на живих мобів і суперника зі спільного лобі; власника не відкидає. Шкоди й руйнування блоків немає.

Біло-перламутрова сфера має пружну анімацію, товстий світлий край, локальну аберацію та короткі просторові шлейфи. [Запис із гри](run/visual-preview/shockwave.gif). Візуал вимикається командою `/flake effects`, незалежно від відкидання.

## Поточні обмеження

- На сервері одне спільне лобі на двох. Підготовка й готовність працюють, **запуск та відновлення раундів ще не підключені**.
- Двоклієнтна перевірка мережевої гри та сумісність зі сторонніми шейдерами ще потрібні.
- Загальний план: [PLAN.md](docs/planning/PLAN.md); перевірка ефекту: [VISUAL_TEST.md](docs/reports/VISUAL_TEST.md).
- Структура коду: [архітектура](docs/architecture.md), [призначення папок](docs/repository-layout.md).

## Розробка

```sh
JAVA_HOME="$HOME/.local/share/jdks/jdk-25.0.5+8" ./gradlew build
JAVA_HOME="$HOME/.local/share/jdks/jdk-25.0.5+8" ./gradlew runClient
```

Можна використовувати інший встановлений JDK 25, задавши відповідний `JAVA_HOME`.
