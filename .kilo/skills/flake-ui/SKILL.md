# Flake UI

Design visually first: clickable slots with real item icons, searchable item modal, live selected-build preview, class button, bottom character stat panel. Old text-heavy three-column UI is not design gold standard. Player preview must never alter actual server inventory. Distinguish passive item and two active equipment items from class ability keybinds. Validate layout at different GUI scales. Keep stats truthful to server rules; use diff highlights only for actual computed stats. Keep UI changes scoped; coordinate changes in build schema with server validation.
