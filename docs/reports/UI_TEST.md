Перевірено 2026-11-09 у реальному Minecraft 26.3 / Fabric API 0.165.2, Java 25.

## Ізоляція

- Джерело світу: `/tmp/opencode/flake-effect-project/run/saves/Flake Visual Test`.
- Для запуску створено окрему копію: `/tmp/opencode/flake-ui-visual-game/saves/Flake Visual Test`.
- Оригінальні світи та налаштування користувача під час цієї перевірки не змінювалися.
- Тимчасовий initializer автоматизував натискання L, активацію справжніх UI-кнопок через Enter, зміну розміру вікна й знімки через `Screenshot.grab`.
- Серверні дані не підмінялися. Тимчасовий initializer та його entrypoint після перевірки видалено з проєкту.

## Перевірені сценарії

1. L відкриває екран створення; `01-create-1280x720-scale3.png`.
2. Enter на «Створити лобі» створює справжнє серверне лобі 1/2; `02-lobby-1280x720-scale3.png`.
3. Enter на «Я готовий» змінює серверну готовність; `03-ready-1280x720-scale3.png`.
4. Tab показує реального гравця, клас, готовність, ping та серверні kills/deaths; `04-tab-1280x720-scale3.png`.
5. Компактний GUI 320×240 зберігає читабельні картки, повні назви кнопок та відступи; `05-ready-960x720-scale3.png`.
6. «Скасувати готовність» підтверджується сервером; `06-not-ready-960x720-scale3.png`.
7. Після повторної готовності команда `/flake class concussed` синхронізує клас «Контужений» і скидає готовність; `06b-build-change-resets-ready.png`.
8. Компактний Tab показує новий серверний клас та статус; `07-tab-960x720-scale3.png`.
9. Вікно 854×480: лобі й Tab без накладань; `08-lobby-854x480.png`, `09-tab-854x480.png`.
10. «Вийти» очищує останнє місце й повертає форму створення; `10-left-lobby-854x480.png`.

Усі 11 знімків відкрито та візуально переглянуто. Внутрішніх накладань тексту/кнопок або обрізаних основних дій не виявлено.

## Виправлення за результатами

- Замінено старі числові коди L, PageUp/PageDown та Enter/Space на `InputConstants.KEY_*`: Minecraft 26.3 використовує SDL-коди.
- Відкриття лобі обробляється на початку клієнтського тіку. Якщо його клавіша збігається з vanilla-клавішею досягнень (типово L), лобі має пріоритет без перезапису налаштувань користувача. Досягнення можна призначити на іншу клавішу в налаштуваннях.
- Раніше збережене неправильне призначення Delete автоматично не переписується: у такому профілі потрібно скинути лише «Відкрити лобі дуелі» до стандартного L через налаштування керування.
- Tutorial-toast вимкнено лише в тестовій копії налаштувань, щоб не закривав верхню частину знімків.

## Межі перевірки

- Один справжній гравець на інтегрованому сервері; два клієнти, заповнене лобі та Tab-пагінація візуально не перевірялися.
- На знімках статистика 0/0 та ping 0 відповідають реальному новому локальному гравцю. PvP-вбивства або смерті не симулювалися; їх підрахунок спирається на серверні vanilla statistics, а не на UI.
- Голосове озвучування не перевірено: у системі відсутня `libflite.so`; клієнт продовжує працювати.
- Це UI підготовки. Раунди, відлік і телепортація не підключені.
